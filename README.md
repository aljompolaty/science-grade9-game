# مختبر العلوم — الصف الثالث المتوسط

تطبيق ويب تقدمي (PWA) يحوّل كتاب «العلوم الطبيعية — الصف الثالث المتوسط» إلى رحلة تعليمية تفاعلية.
يعمل على الجوال والحاسوب، ويمكن تثبيته من المتصفح واستخدامه دون إنترنت.

**جرّب التطبيق:** https://aljompolaty.github.io/science-grade9-game/

## التثبيت على أندرويد
1. افتح الرابط في متصفح Chrome على الهاتف.
2. اضغط زر **ثبّت التطبيق على جهازك** في الصفحة الرئيسية، أو من قائمة Chrome (⋮) اختر **تثبيت التطبيق** / **إضافة إلى الشاشة الرئيسية**.
3. تظهر أيقونة «مختبر العلوم» على الشاشة الرئيسية، ويعمل التطبيق بعدها حتى من دون إنترنت.

## التشغيل والنشر

```bash
npm install
npm run dev      # للتطوير
npm run build    # نسخة النشر في مجلد dist
npm run deploy   # بناء ونشر على GitHub Pages (فرع gh-pages)
```

## قاعدة المحتوى

- نصوص الكتاب وصوره تُعرض **حرفياً دون أي تغيير** (بطاقات «من الكتاب» مع رقم الصفحة).
- شرح المعلم «نور» والأسئلة السريعة والألعاب طبقة مساعدة للتبسيط فقط.
- صور الأشكال مقتطعة من النسخة الأصلية للكتاب ومحفوظة في `public/book/`.

## البنية

| المسار | المحتوى |
|---|---|
| `src/data/units.js` | قائمة الوحدات السبع (من قائمة المحتويات) |
| `src/data/unit1.js` | الوحدة الأولى: نص الكتاب + الشرح + الألعاب |
| `src/screens/` | الرئيسية، الوحدة، المحطة، تقويم الوحدة، الإنجازات |
| `src/games/` | الصندوق المغلق، التصنيف، رسام الأوصاف، النظام الشمسي، مقياس الرسم، بطاقات الخلاصة، اختبر نفسك |
| `src/components/Teacher.jsx` | الروبوت المعلم «نور» وصوته |

## صوت المعلم

شرح المعلم مسجّل مسبقاً بـ ElevenLabs بصوت **Yousif** (سوداني) — `voice_id: gHrEYXAK42DJ7wvGjAKs`، النموذج `eleven_multilingual_v2`.
كل جملة محفوظة في `public/voice/` باسم مشتق من نصها (`src/lib/voiceKey.js`). إذا عُدّل نص الشرح يجب توليد تسجيل جديد له، وإلى ذلك الحين يُستخدم صوت الجهاز احتياطياً.

## إضافة وحدة جديدة

1. اقتطع صور أشكال الوحدة إلى `public/book/`.
2. أنشئ `src/data/unitN.js` بنفس بنية `unit1.js` (المحطات ← مقاطع `book` / `figure` / `teach` / `check` / `game`).
3. اربطها في `src/data/units.js` بالخاصية `content`.
4. سجّل جمل `teach` بصوت يوسف واحفظها في `public/voice/`.
